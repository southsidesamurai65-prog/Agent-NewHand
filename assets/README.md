# 配图清单（assets）

这个目录存放本系列教程（`basics.md` / `opencode.md` / `codex.md`）的配图。

- ✅ **已提供**：图片已放好，教程里能直接显示（来源见下方"素材来源"）。
- ⬜ **待截图**：网上没有可用/合适的画面，需要你按"截什么画面"自行截图，并**用表格里的文件名保存**。

> 截图小技巧：
> - Windows 自带截图：按 `Win + Shift + S` 框选，截图进剪贴板，再粘贴到「画图」里另存为 PNG。
> - 尽量只截**关键区域**，不要整个桌面，方便阅读。
> - 建议统一宽度 1200～1400px，画面清晰但文件别太大。
