# AI 编程助手图文教程（完全不懂编程也能用）

一套**面向零基础读者**的 AI 编程助手教程：不讲玄乎的原理，用大量**真实截图**和"照着做"的实例，带你把常用工具从安装到实战完整走一遍。

每个功能都按 **「是什么 → 怎么输入 → 屏幕会出现什么 → 结果」** 四步演示，并配有 🧪 动手练习和清晰的验收标准。

## 怎么读

1. 先花 10 分钟读 **[共用基础篇](basics.md)**，把"终端 / 命令 / 路径 / Git / Token"弄明白。
2. 再按兴趣挑一篇，从第 2 章开始跟着做。
3. 每章末尾的 🧪 练习建议亲手做一遍。

## 关于截图

教程中的配图优先使用可公开获取的**真实截图**（官方素材、公有领域图、官方文档图）。所有配图的来源与授权都记录在 [`assets/README.md`](assets/README.md)；少数暂缺的图已标为"待补充"，可按清单自行补齐。
